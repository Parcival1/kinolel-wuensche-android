# KinoLel Wünsche (Android) – Testanleitung

1. `KinoLel-Wuensche-<Version>.apk` auf dem Handy/Tablet laden und installieren („Unbekannte Apps installieren“ für den
   Browser erlauben).
2. **KinoLel Wünsche** öffnen → Anmeldeseite der Wunschseite; mit den KinoLel-Zugangsdaten anmelden.
3. Oben **Deutsch / Magyar** umschalten → deutsche bzw. ungarische Wunschseite; App schließen und neu öffnen → Wahl bleibt.
4. Wünschen, Suchen, „Problem melden“ ausprobieren.
5. **Links:** In KinoLel (Jellyfin) auf den Wünsche-Link/Stern tippen oder in einer Nachricht einen Link auf
   `https://wuensche.kinolel.de/...` antippen → **öffnet diese App** (nicht den Browser).
   Falls doch der Browser kommt: Einstellungen → Apps → KinoLel Wünsche → „Standardmäßig öffnen“ → Links zulassen.
6. Updates kommen künftig von selbst (Hinweis beim Start).
